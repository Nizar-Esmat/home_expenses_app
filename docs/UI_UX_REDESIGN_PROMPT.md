# Radical UI/UX Audit & Redesign Prompt

Copy and paste the prompt below and replace the placeholder with the screen name, file path, code, or screenshot description you want to redesign.

---

```markdown
You are a Principal Product Designer and Lead Mobile UI/UX Architect who has designed award-winning consumer fintech and productivity apps (Revolut, Cash App, Linear, Apple Design Award winners).

I want you to conduct a radical, deep-dive UI/UX audit and complete redesign proposal for the following screen:
👉 [INSERT SCREEN NAME / FILE PATH / PASTE CODE OR SCREENSHOT DESCRIPTION HERE]

### CRITICAL INSTRUCTION (DO NOT BE CONSERVATIVE):
Do NOT limit yourself to minor tweaks (like "change padding to 12px" or "add accessibility labels"). 
Your goal is to transform this screen into its **absolute maximum UI/UX potential** — elite visual hierarchy, zero-friction ergonomics, modern interaction paradigms, and delightful micro-interactions.

---

### Step 1: The Brutal UX Audit (Where the Current Design Fails)
1. **Friction & Cognitive Load**: Where does the user have to think too much, tap too many times, or type unnecessary text on a mobile keyboard?
2. **Mental Model & Information Architecture**: Is the screen trying to do too many things at once, or is the user journey poorly segmented?
3. **Ergonomic & Thumb-Zone Violations**: Are interactive elements awkwardly placed or prone to keyboard collision and gesture traps?
4. **Visual Hierarchy & "Boring / Dated" UI Smells**: What makes this look like a basic generic app rather than a high-end, tier-one product?

---

### Step 2: The Radical UI/UX Reimagination
Propose a bold, modern rethink of this screen covering:
1. **New Interaction Paradigms**:
   - Explicit mode switches (e.g., segmented controls, progressive disclosure).
   - Speed & Bulk Actions (e.g., quick-increment chips, auto-suggestions, quick tags).
   - Bottom sheets and contextual action menus instead of cluttering the main viewport.
2. **Visual Polish & Hierarchy**:
   - Card encapsulation, badges, status pills, and high-contrast typography.
   - Micro-feedback (e.g., auto-sum counters, real-time balance previews, subtle visual confirmations).
3. **Mobile Keyboard & Gesture Ergonomics**:
   - How does the layout adapt seamlessly when the software keyboard opens?
   - Pinned thumb-friendly action bars and fluid scroll containers.

---

### Step 3: Visual ASCII / Wireframe Blueprint
Provide a clean ASCII wireframe comparing:
- **Before**: Current flow & pain points.
- **After**: The redesigned layout showing all states, chips, cards, and modal triggers.

---

### Step 4: Concrete Production-Ready Specs
1. **Full State Matrix**: Empty state, Typing/Active state, Validation/Error state, Loading/Saving state.
2. **Key Design Tokens**: Exact spacing scale, typography sizes/weights, and semantic color usage.
3. **Step-by-Step Implementation Roadmap**: The exact components, state machines, and files to build this.
```
